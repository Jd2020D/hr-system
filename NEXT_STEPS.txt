🚀 TO RUN THE APPLICATION:

Option 1: Automated (Recommended)
──────────────────────────────────
$ ./run.sh

This will start everything automatically!

Option 2: Manual Steps
───────────────────────
$ cp apps/api/.env.example apps/api/.env
$ cp apps/web/.env.example apps/web/.env
$ docker-compose up -d
$ docker-compose exec api npx prisma generate
$ docker-compose exec api npx prisma migrate deploy
$ docker-compose exec api npm run seed

❓ TROUBLESHOOTING:
───────────────────
• Docker not running?
  → Start Docker Desktop first!

• MySQL connection failed?
  → Wait 30-60 seconds for MySQL to initialize
  → Check: docker-compose logs mysql

• Ports already in use?
  → Stop services using ports 4000, 5174, 3306, or 8080

• Need help?
  → See INSTALL_INSTRUCTIONS.md for detailed troubleshooting
